# Simulation Formulas

This document records the core mathematical formulas and physics approximations utilized within the Simulation Engine to calculate dynamic states.

## Interpretation Sources
- `component.json`: Current local physics calculations.
- `connection.json`: Current graph capacities and transfer bottlenecks.
- `external.json`: External conditions (e.g., Ambient Temp, Wind Speed).

---

## Power Allocation

```text
AvailablePower = sum(Output(Generators)) + sum(Discharge(Batteries))
Demand = sum(InputRequirements(Consumers))
```

**Distribution Logic:**
- If `AvailablePower >= Demand`: All components function at 100% capacity.
- If `AvailablePower < Demand`: Proportional power allocation occurs (brownout).
- If `AvailablePower < 35% Demand`: Cascading total failure initiates, shedding load based on hierarchy priorities (Life Support > Communications > Science > Comfort).

## Thermal Regulation (HVAC)

Heat is generated by running equipment and lost to the environment.

```text
HeatGen = sum(Heat(Active_Equipment))
DeltaT = (HeatGen - CoolingCapacity(HVAC) - VentLoss) * Thermal_Constant
```

**Failsafe Logic:**
- If interior ambient temperature > 40°C, the HVAC target set-point automatically offsets by 2°C increments to prevent compressor freezing.
- If temperature > 55°C, sensitive electronics (Servers, Comms) auto-shutdown to prevent hardware damage.
